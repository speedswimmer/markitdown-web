Why Markdown for ChatGPT and Claude?

      
AI models work in tokens, and every token costs compute time and money. A PDF or Word file carries layout, fonts and formatting that don't matter for the content. Markdown is plain text with a few characters for structure, such as # for headings or | for tables. The model sees exactly the content and how it is organized, and the same information fits into the context window with fewer tokens.

      
Markdown also works well for RAG applications, knowledge bases and note-taking apps: it is easy to search, split into sections and version with Git.

    


    

      

        
Frequently asked questions

        

          Is the conversion free?
          
Yes. There is no sign-up, no account and no advertising. If you'd like to support the project, you can buy me a coffee.

        

        

          Are my files stored?
          
No. The file is processed in memory only for the conversion and discarded afterwards. The result is not stored either. Details are in the privacy policy (in German).

        

        

          Where are my files processed?
          
On my own physical server in Germany, not in a cloud. Conversion and OCR run entirely there. No content is sent to an AI service or any other provider. Only the encrypted transfer between your browser and the server passes through Cloudflare; see the privacy policy (in German) for details.

        

        

          Does it work with scanned PDFs?
          
Yes. If a PDF has no readable text, for example because it was scanned, the OCR engine Tesseract reads the text, right on my server. This works well for letters and running text; tables in scans are not always recognized cleanly. The number of pages is limited for scans.

        

        

          Are tables preserved?
          
Yes. Tables from PDF, Word, PowerPoint and Excel come out as Markdown tables. In Excel files, every sheet becomes its own table with a heading.

        

        

          Which files are supported?
          
PDF, DOCX, PPTX, XLSX and CSV. For CSV files, such as online banking or Excel exports, the character set and the delimiter (semicolon, comma or tab) are detected automatically. Please save older formats such as DOC, PPT or XLS in the newer format first. The maximum file size is shown in the upload box.

        

        

          What does “text coverage” mean?
          
For digital PDFs, the tool checks after the conversion how many words and numbers from the PDF's text layer appear in the Markdown. Running headers and footers are dropped on purpose, so the value is rarely 100 %. Pages below 90 % are listed individually. Scans get no value because there is no text layer to compare against.

        

        

          How does the conversion work?
          
PDFs with text are converted by PyMuPDF4LLM, which understands page layouts with columns and tables. Word, PowerPoint and Excel are handled by Microsoft's MarkItDown, and scans are read by OCRmyPDF with Tesseract.
